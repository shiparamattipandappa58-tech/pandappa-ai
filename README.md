# Student Attendance & Database Management System
**Government First Grade College, Byndoor**  
*Department of Computer Applications (BCA Mini/Major Project)*

## About Project
This web-based application is designed for Government First Grade College, Byndoor, to manage student records, user authentication (Admin, Faculty, Students), and daily attendance tracking. It features an automated WhatsApp alert system that instantly notifies parents if a student is marked as "Absent".

## Tech Stack
- **Frontend:** HTML5, CSS3, Jinja Templates
- **Backend:** Python (Flask Framework)
- **Database:** MySQL
- **Automation:** PyWhatKit (for WhatsApp notifications)

## How to Run in Termux / Local Machine
1. Clone the repository:
   \`\`\`bash
   git clone https://github.com/your-username/college-database-system.git
   cd college-database-system
   \`\`\`
2. Install dependencies:
   \`\`\`bash
   pip install -r requirements.txt
   \`\`\`
3. Run the application:
   \`\`\`bash
   python app.py
   \`\`\`
